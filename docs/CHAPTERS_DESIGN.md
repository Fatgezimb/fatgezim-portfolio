# Revision direction — one desk, a connected body of work

The owner’s October 15 critique supersedes the previous visual treatment and section order. Verified professional facts, working demos, public links and approved resume bytes stay authoritative. Phase 1 approval is already recorded; this is an authorized visual/narrative revision.

Subject: a founder and hands-on engineer whose scientific/clinical training changes how he builds. Audience: technical collaborators and hiring teams. Page job: make that connection visible through evidence and interaction.

Palette: desk lilac #f1eff6, deep graphite #252137, iris #6245a5, microscope sea glass #a8dcc5, studio periwinkle #c8c9ee, brass #dfb65b. Bricolage Grotesque for large, sharply composed titles; Geist for reading; Geist Mono for actual controls, figure captions and dates.

Page sequence:
```
Desk: five objects, five ways into the work (existing signature)
Meet: large portrait / personal thesis / three routes through the story
Investigate: dark research lightbox, original fluorescence and tracing figures
Build: wide application workbench; seven real, navigable product samples
Inspect: a tangible input-to-decision walkthrough, source rows stay visible
Explore: a full-width physical form/light studio, visitor changes the object
Lead: current organizations / earlier work in an intentional career composition
Connect skills: choose a discipline, see tools beside a specific work example
Keep learning: education as a path; credentials / small personal film moment
Continue: oversized invitation, functional contact form and approved downloads
```

The recurring signature is the desk opened up into working instruments: a lightbox, a browser, a process bench, a material study and a field notebook. Each has a distinct composition but shares material, typography and interaction language. No repeated three-column manifesto, arbitrary card wall, invented metrics or counterfeit project imagery.

Self-critique: headings alone would repeat the last failure. Each major chapter must contain something inspectable and visually dominant. Career/education must retain scanability rather than turn every fact into a game. The scientific figures must remain attributable and unmodified. The creative study is an original interactive portfolio experiment, not a claimed past Blender commission. Motion reveals relationships and user-driven changes; it never supplies missing substance.

Implementation: retain all existing anchor IDs, actual project workflows, accessible state/focus and no-JS reading. Native controls and responsive compositions. Lazy Three.js on demand/in view, static rendered poster, reduced-motion and constrained-device fallbacks, offscreen stop and cleanup. Browser screenshots at each chapter before final responsive/accessibility regression and deployment.
