## Scientific data

NeuroStack uses DANDI 000582 version `0.251111.2151`, recording `sub-10073/ses-17010302`, medial entorhinal cortex layer II, Long Evans rat, Sargolini et al., CC BY 4.0. The source derivative and SHA are disclosed in its Provenance panel. Ten source 100 ms rate bins are averaged for each one-second displayed bin; the population series averages all eight units. Raster times come from the same artifact. The original measured-looking placeholder values and arbitrary line were replaced in the active portfolio.

The deployed NeuroStack HTML responds successfully, but its client bootstrap and font URLs currently request the domain root and return 404. Its lab controls do not hydrate. The portfolio therefore offers a working artifact preview and public source link. Repairing that separate application is outside this portfolio change.

## Public embeds

Bela's synthetic dashboard, Caregiver's public landing/preview and RBT rendered inside sandboxed frames from localhost and a simulated production portfolio ancestor. External responses and security headers were untouched. Subsequent integrated checks cover the actual portfolio windows and returning to the local sample. Frames load only after explicit activation; only the active project mounts a frame. A new-tab link remains available regardless of external loading behavior. No authentication or checkout workflow is represented as tested.

Caregiver's public preview is a marketing surface. The source-backed learning sample does not claim to unlock the authenticated library. RBT sample progress and StepSpark sample reviews last for the current visit. Synthetic operations/reimbursement records are explicitly distinguished from real scientific artifacts.
