# Three evidence-led projects

Owner request, October 15, 2026: extend the earlier forecasting work, use the supplied YouTube dataset, and build a high-fidelity example relevant to M.C. Dean.

## Grid Forecast Lab

Remake the PJME hourly-demand exercise as a reproducible day-ahead forecasting project. Credit the owner's public Kaggle fork and Rob Mulla's original tutorial. Compare calendar/lag models against yesterday and last-week baselines. Use expanding chronological validation, a separate interval-calibration year, and a final untouched test year. Expose individual forecast days, monthly error, coverage and timestamp-quality decisions. Historical replay, with every input available at the forecast origin.

## Video Signal Lab

The requested Kaggle dataset is explicitly synthetic. Its engagement variables are generated from views, and its viral label is the top quintile of views. Build a classification and leakage-audit workbench: metadata-only models, an explicitly retrospective engagement comparison, independent validation/test partitions, probability calibration, threshold exploration and category-level uncertainty. This demonstrates analytical judgment; the dataset cannot establish real creator outcomes. Display the synthetic classification beside the analysis.

## Relay — Commissioning Readiness

An independent workflow prototype for modular power-system turnover. M.C. Dean documents Level 3/4 factory commissioning and Level 5 site integration, with baseline information handed to operations. Its October 14, 2026 expansion announcement provides current context for scale. It also already describes integrated project software; an internal software gap is unconfirmed.

Proposed problem: keep acceptance evidence consistent with equipment revisions and prerequisite tests as modules move between factory and site. Fictional assets, evidence and events. A dependency graph computes readiness; revised or rejected evidence invalidates downstream acceptance; corrective actions, witness notes and exports leave a reviewable event history. Browser-local persistence makes the prototype usable without implying production authorization, equipment control, or a company relationship.

The strongest hiring story is the domain engine: deterministic transitions, explicit blockers, revision propagation, tested invariants and inspectable handover packages. The interface is an engineering workbench with an asset register, a staged acceptance path and an evidence inspector. Slate, white and restrained amber; compact operational typography; motion only for state changes. Mobile stacks the same decisions and actions.
